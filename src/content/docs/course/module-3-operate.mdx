**Time:** ~30 minutes  
**Goal:** Operate workflows with evidence discipline and realistic adoption expectations.

## 1. Verification without agent trust (~8 min)

Read [Evidence not trust](/concepts/evidence-not-trust/).

Rules of thumb:

- Typed artifacts beat conversation history
- Read-backs beat self-reported completion
- Graders beat "ask another agent if it looks right"

## 2. Costing boundary (~5 min)

**Price the workflow, not the tool.**

| Work type | Typical economics |
| --- | --- |
| Scheduled, bounded, cheap-per-unit | Metered keys per workflow win |
| Heavy, interactive, unpredictable | Flat subscription may win |

Pin the cheapest model that finishes the unit. Bounded work belongs on a meter you can read per run.

## 3. The productivity J-curve (~7 min)

Expect a dip before compound gains. New tooling adds friction before it removes toil.

**Safe practice** (mistakes do not hit performance reviews) is an environment intervention — not a training module. Protect it when the plan gets compressed.

## 4. Override rate as health (~5 min)

Near-zero override is not success. It may mean:

- Psychological safety is missing (people won't contradict the model), or
- People cannot detect errors (skill gap)

Healthy band is often cited around **10–30%** override on consequential outputs — enough skepticism, not automation bias.

## 5. Defer the conductor (~5 min)

Add a routing layer only when **routing between workflows** is the friction — not because the diagram looks better with a manager agent.

Per-workflow executors with shared evidence beat all-to-all agent chat.
