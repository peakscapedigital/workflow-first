## Pair review (5 minutes)

Swap with a partner. Can they tell **when this workflow succeeded** without asking you? Can they name what happens when evidence fails?

If not, the contract is still role-shaped prose.

## Debrief

- Which field was hardest: Job, Connections, or Evidence?
- Did anyone's contract expose a **Ready?** problem (data not reachable)?
