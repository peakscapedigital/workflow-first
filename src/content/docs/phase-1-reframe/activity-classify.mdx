## Instructions (10 minutes)

Pick one AI idea your team has actually floated, not a hypothetical. Work individually, then share one example with the group.

Use the [log vs profile worksheet](/downloads/log-vs-profile-worksheet/) or the table below.

| Field | Your answer |
| --- | --- |
| Idea name / one-line description | |
| **Sense** (A / B / C) | |
| **Workflow or role?** Is there an exit condition? | |
| **Gate 0, Ready?** (Y / N / Not sure) | |
| **Gate 0, Shape?** (rule / script / workflow / harness) | |
| One sentence: what would **done** look like? | |

## Mini example (filled)

| Field | Example |
| --- | --- |
| Idea | "SEO agent" that drafts blog posts |
| Sense | A (scoped assistant) |
| Workflow or role? | Role, "good draft" is not an exit condition |
| Ready? | Partially, no shared rubric for quality |
| Shape? | Workflow units (research, draft, grade) before any persona |
| Done | Published post passed rubric + human approval |

## Debrief prompts

- How many ideas were **role-shaped** vs **workflow-shaped**?
- Did anyone's "done" sentence include **evidence** (a check), not just output?
- Which ideas failed **Ready?** before they failed **Shape?**
