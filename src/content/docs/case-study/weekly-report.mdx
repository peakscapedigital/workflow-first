This case study shows **Sense B**: an orchestrated workflow with a defined outcome and exit condition. There is no analyst persona, charter, or journal anywhere in the chain.

## What it does

On a schedule, the system:

1. Selects the reporting window
2. Fetches missing metrics from live analytics
3. Joins client configuration and ground truth
4. Grades the packet: numbers must reconcile
5. **Blocks delivery** if grading fails
6. Publishes to Shared Drive only when evidence passes

Nobody described an analyst to get analyst-like output.

## Contrast with role-shaped approach

| Role-shaped (top-down) | Workflow-shaped (this case) |
| --- | --- |
| Charter grows each failure | Steps have named acceptance checks |
| Re-orient every session | Run N identical to run 1 |
| Produces drafts | Produces or refuses |
| "Agent" in name | No persona in architecture |

## What to notice

- **Human floor** appears only where judgment or approval is required, not between every step
- **Assurance** is a step with evidence, not an agent asking "did it go well?"
- **Exit condition** is explicit: delivered PDF with reconciled numbers, or blocked with findings
