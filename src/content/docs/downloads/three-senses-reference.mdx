# Three Senses of Agent

| Sense | What it is | Example |
| --- | --- | --- |
| **A** Scoped assistant | Topic bot on tenant: prompt + sources + few actions + human gates | Copilot Studio, Power Automate + chat |
| **B** Orchestrated workflow | Steps with defined outcome and exit condition | Scheduled reporting, review worker |
| **C** Autonomous persistent | Own runtime, memory, unattended identity | Portfolio bots with cross-run memory |

**Same workflow unit, different wrapper.**

| They say | Likely sense |
| --- | --- |
| "Change the workers" | A |
| "Build agents" for one outcome | A or B |
| "Portfolio of agents" with own identity | C |
