---
title: Evidence not trust
description: Why agent-to-agent handoffs fail, and what independent evidence looks like.
---

When two role-shaped agents collaborate, nobody answers: **who checks the one that spoke?**

Agent A receives Agent B's *account* of what happened. The only checker available is another model with the same weakness. The failure is usually not lying, it is **summarizing**. The caveat drops. The number rounds. The headline stays.

Compressed truth and fabrication arrive in the same fluent prose with no provenance.

## Build the unit instead

Neither agent should be the source of truth. The metric read-back, the graded packet, the reconciled export belong to **no role**. Executors call the same unit and read the same artifact.

The verifier is not an agent. It is the unit proving its own work.

## Done means

1. A **typed artifact** exists (file, record, structured output)
2. **Acceptance checks** ran against it
3. Checks **passed**: with findings captured when they did not

"I finished the task" from the model is not evidence.

## Grading contract

```json
{
  "passed": false,
  "findings": [
    "Sessions total 12,450 does not match GA4 read-back 11,902"
  ]
}
```

Findings feed a repair loop (capped retries, fail-closed). That is the piece that separates systems from prompt chains.

## Conductor later

A conductor that asks sub-agents "how did it go?" repeats the same hop with a nicer diagram. A conductor that reads **read-backs** is different, and cannot exist until units report for themselves.
