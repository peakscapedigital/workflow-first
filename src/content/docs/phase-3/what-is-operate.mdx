---
title: What is the Operate phase?
description: Phase 3 covers running workflows with evidence, cost discipline, and realistic adoption.
---

Design produced a contract on paper. Operate is what keeps it **honest in production**: verification without agent trust, per-workflow costing, adoption curves, and knowing when **not** to add another agent.

Phase 3 is not "turn on the chatbot." It is:

- Evidence and graders stay true after launch
- Costs attach to the workflow unit, not the vendor invoice
- People know when to override — and when zero override is a bad sign
- Routing layers wait until routing is the actual friction

## Lessons in this phase

| Lesson | Focus |
| --- | --- |
| Evidence not trust | Artifacts and read-backs, not agent summaries |
| Costing boundary | Price the workflow, pin the model |
| Productivity J-curve | Expect dip before compound gains |
| Override rate | Health band, not "AI always right" |
| Defer the conductor | No manager-agent until units report for themselves |
| Activity | One-quarter commitment with before metric |
